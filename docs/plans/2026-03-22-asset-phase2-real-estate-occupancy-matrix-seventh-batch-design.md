# 不动产占用状态矩阵第七批设计

## 1. 目标

在第六批已经完成“导出字段配置、轨迹分组视图、联动筛选快捷入口”的基础上，继续补齐三项更偏分析效率和跨页签协同的能力：
1. 导出模板预设
2. 轨迹批注视图
3. 跨页签联动入口

本批继续限定为前端体验增强，不新增后端接口，不调整数据库结构，不改变占用领域状态机。

## 2. 设计边界

### 2.1 保持不变

- 不新增 SQL
- 不修改占用相关后端接口
- 不调整占用创建、变更、释放的业务规则
- 不新增独立页面
- 不改动巡检、整改、处置的业务数据结构

### 2.2 本批新增

- 在现有导出字段配置之上增加模板预设，提升常见导出场景效率
- 在现有平铺/分组轨迹之外增加批注视图，突出“原因、释放说明、状态解释”
- 在占用页签内增加跨页签联动入口，直接切到总览、巡检、整改、处置页签

## 3. 交互设计

### 3.1 导出模板预设

在“导出字段配置”面板内新增三组预设：
- 运营摘要：关注当前归口、责任人与位置
- 审计复盘：导出完整字段
- 释放分析：强调释放时间、释放原因与变更原因

预设规则：
- 点击预设后直接覆盖当前字段勾选结果
- 用户仍然可以在预设基础上继续手工勾选
- 最终导出仍然只针对当前筛选结果

### 3.2 轨迹批注视图

在“平铺视图 / 分组视图”之外新增“批注视图”：
- 每条轨迹渲染为一张批注卡片
- 卡片突出三类信息：
  - 状态说明
  - 占用批注
  - 释放批注
- 批注视图不改变筛选和排序口径，只改变展示方式

### 3.3 跨页签联动入口

在占用摘要区增加统一的“跨页签联动”入口，支持：
- 回总览核对主档
- 看巡检联动
- 看整改进展
- 看处置关联

实现口径：
- 占用页签不推新路由
- 通过子组件事件通知详情壳切换 `activeTab`
- 仍沿用详情壳现有的页内 Tab 组件切换模式

## 4. 组件改造

目标文件：
- `art-design-pro/src/views/asset/real-estate/detail/components/occupancy-panel.vue`
- `art-design-pro/src/views/asset/real-estate/detail/index.vue`

本批改造点：
- OccupancyPanel 增加导出预设配置
- OccupancyPanel 增加批注视图分支
- OccupancyPanel 增加跨页签联动按钮并向父层发事件
- 详情壳接收 `switch-tab` 事件并切换当前页签

3. 点击跨页签联动入口后发出切 Tab 事件
4. 详情壳接收联动事件后切换到目标页签
