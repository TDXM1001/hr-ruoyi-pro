# 不动产占用状态矩阵第九批设计

## 1. 目标

在第八批已经完成“预设命名自定义、批注导出、跨页签回跳记忆”的基础上，继续补齐三个更偏长期使用效率的能力：
1. 预设复制新建
2. 批注模板化
3. 回跳来源提示

本批仍限定为前端增强，不新增后端接口，不调整数据库结构，不改变占用业务状态机。

## 2. 设计边界

### 2.1 保持不变

- 不新增 SQL
- 不修改占用相关后端接口
- 不新增独立页面
- 不调整占用发起、变更、释放的业务规则
- 不改动巡检、整改、处置的数据结构

### 2.2 本批新增

- 允许资产管理员基于系统预设复制出自定义导出预设，并持久化到本地
- 允许在批注视图中切换不同批注模板口径
- 允许详情壳在“返回占用联动”旁边展示本次联动来源

## 3. 交互设计

### 3.1 预设复制新建

在“导出字段配置”面板中新增“复制新预设”区域：
- 可选择复制来源：
  - 当前字段配置
  - 运营摘要
  - 审计复盘
  - 释放分析
  - 已有自定义预设
- 输入新预设名称后点击“复制创建”
- 创建成功后立即出现在预设列表中
- 自定义预设持久化到 `localStorage`
- 预设只影响字段组合，不引入后端保存

### 3.2 批注模板化

在“批注视图”中新增模板切换：
- 标准模板
- 管理视角
- 审计视角

模板切换影响：
- 卡片中的“状态说明”
- 占用批注和释放批注的前置说明口径
- `导出批注` 生成的 CSV 内容

模板本身只作用于前端呈现，不改写原始业务字段。

### 3.3 回跳来源提示

当用户从占用页签联动到总览 / 巡检 / 整改 / 处置时：
- 详情壳继续保留“返回占用联动”按钮
- 同时展示“来自：xxx”的来源提示
- 来源提示与回跳记忆一起持久化到 `sessionStorage`
- 刷新后仍可恢复
- 点击回跳后清空来源提示

- 详情壳增加回跳来源展示与记忆恢复

## 5. 测试设计

### 5.1 定向测试

新增测试场景：
1. 复制系统预设生成自定义预设，并在重新挂载后恢复
2. 切换批注模板后，批注卡片文案随之变化
3. 批注导出跟随当前模板口径
4. 占用联动切到其他页签后显示“来自：xxx”
5. 刷新后来源提示仍存在，回跳后清空

### 5.2 回归测试

继续覆盖不动产详情相关页面，确保不影响：
- 占用页签既有筛选、分组、导出、回跳
- 巡检任务页
- 整改单页
- 整改完成页
- 整改审批挂载位
