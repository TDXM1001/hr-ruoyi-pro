# 不动产占用状态矩阵第六批设计

## 1. 目标

在第五批已经完成“摘要卡片联动轨迹定位、筛选条件持久化、导出占用轨迹”的基础上，继续补足三个直接影响资产管理员分析效率的能力：
1. 导出字段配置
2. 轨迹分组视图
3. 联动筛选快捷入口

本批仍限定为前端体验增强，不新增后端接口，不调整数据库结构，不改变占用业务状态机。

## 2. 设计边界

### 2.1 保持不变

- 不新增 SQL
- 不修改占用相关后端接口
- 不新增独立页面
- 不改变“发起占用 / 变更占用 / 释放占用”的业务口径
- 不改动现有整改、巡检、审批相关页面

### 2.2 本批新增

- 允许用户按需勾选导出字段，只导出当前需要的列
- 允许在列表视图与分组视图之间切换，更快判断当前有效占用与已释放轨迹
- 允许从状态矩阵直接触发联动筛选，减少手工操作步骤

## 3. 交互设计

### 3.1 导出字段配置

- 在“导出占用轨迹”按钮旁新增“导出字段”配置入口
- 点击后展开字段配置面板
- 默认选中字段：
  - 占用单号
  - 占用状态
  - 使用部门
  - 责任人
  - 使用位置
  - 占用开始
  - 释放时间
- 可选字段继续补充：
  - 发起/变更原因
  - 释放原因
- 用户勾选结果持久化到 `localStorage`
- 导出时只输出当前勾选字段，并保持当前筛选结果范围

### 3.2 轨迹分组视图

- 轨迹区支持两种模式：
  - 列表视图
  - 分组视图
- 分组视图按 `ACTIVE / RELEASED` 分组展示
- 每组展示分组标题、数量、组内轨迹
- 分组视图仍然复用现有筛选结果，不单独请求数据

### 3.3 联动筛选快捷入口

- 在状态矩阵每张卡片下增加快捷入口按钮
- 目标场景：
  - 无有效占用 -> 快速查看全部轨迹
  - 存在有效占用 -> 快速筛到 `有效占用`
  - 已释放历史 -> 快速筛到 `已释放`
- 快捷入口触发后：
  - 自动设置状态筛选
  - 清空关键字
  - 重置时间维度为 `全部时间`
  - 排序回到 `最新在前`
  - 滚动到轨迹区
