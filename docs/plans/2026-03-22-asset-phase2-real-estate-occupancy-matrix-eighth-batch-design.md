# 不动产占用状态矩阵第八批设计

## 1. 目标

在第七批已经完成“导出模板预设、轨迹批注视图、跨页签联动入口”的基础上，继续补齐三个更偏可持续使用的细节能力：
1. 预设命名自定义
2. 批注导出
3. 跨页签回跳记忆

本批继续限定为前端体验增强，不新增后端接口，不调整数据库结构，不改变占用业务状态机。

## 2. 设计边界

### 2.1 保持不变

- 不新增 SQL
- 不修改占用相关后端接口
- 不新增独立页面
- 不改变占用创建、变更、释放的业务规则
- 不改动巡检、整改、处置的数据结构

### 2.2 本批新增

- 允许资产管理员自定义导出预设显示名称，并持久化
- 允许在批注视图下直接导出批注型 CSV
- 允许从占用页签联动出去后，在详情壳中保留“返回占用”的回跳入口

## 3. 交互设计

### 3.1 预设命名自定义

在“导出字段配置”面板中新增“命名设置”：
- 支持对 3 个预设修改显示名：
  - 运营摘要
  - 审计复盘
  - 释放分析
- 修改后点击“应用命名”生效
- 名称持久化到 `localStorage`
- 预设字段本身不变，只改显示名

### 3.2 批注导出

当用户切到“批注视图”时，新增独立“导出批注”按钮：
- 导出范围：当前筛选结果 `filteredRecords`
- 导出格式：CSV
- 导出列：
  - 占用单号
  - 轨迹状态
  - 状态说明
  - 占用批注
  - 释放批注
- 文件名：`<assetCode>-occupancy-annotations.csv`

### 3.3 跨页签回跳记忆

当用户通过占用页签的联动入口切到总览 / 巡检 / 整改 / 处置时：
- 详情壳记录本次来源页签为 `occupancy`
- 在目标页签头部显示“返回占用联动”按钮
- 刷新后仍保留该回跳入口
- 点击回跳后：
  - 返回 `occupancy`
  - 清空回跳记忆
