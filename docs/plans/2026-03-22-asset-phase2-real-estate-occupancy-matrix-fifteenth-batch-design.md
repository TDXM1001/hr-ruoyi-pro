# 不动产占用状态矩阵第十五批设计

## 1. 目标
本批继续沿用占用矩阵治理线，不增加后端接口，不增加 SQL，只在占用页签内补齐治理工具区，把前几批分散形成的治理能力收敛为可管理、可复用、可回看的统一工具能力。

## 2. 范围
仅调整以下文件：
- `art-design-pro/src/views/asset/real-estate/detail/components/occupancy-panel.vue`
- `art-design-pro/tests/views/asset-real-estate-occupancy-panel.test.ts`

## 3. 设计

### 3.1 治理工具区
在“导出字段配置”区域新增“治理工具”入口，展开后形成统一工具区，承载三类治理能力：
- 导入策略模板
- 趋势快照管理
- 重置记录

目标是把治理型功能从主展示区收敛到一个稳定区域，避免占用页签继续膨胀。

### 3.2 导入策略模板
在导入预览已有的逐条策略基础上，补齐“模板化”能力：
- 可将当前导入预览的全局策略 + 逐条覆盖策略保存为模板
- 模板按资产维度持久化到 `localStorage`
- 模板列表支持：应用、删除
- 应用模板时，按 `label + conflictType` 匹配当前预览项
- 未匹配项继续沿用当前全局策略
- 系统预设冲突仍不允许覆盖

### 3.3 多快照治理
将单一趋势快照升级为可管理的快照列表：
- 钻取时可输入快照名称；为空则自动命名
- 保存后进入快照列表
- 保留当前页顶部的“恢复快照 / 清空快照”快捷入口，但它默认作用于最近一次快照
- 治理工具区中的快照列表支持：恢复、删除
- 快照按资产维度持久化到 `localStorage`

### 3.4 重置记录
对“只重置趋势 / 只重置来源 / 全部重置”三种动作新增记录留痕：
- 记录时间
- 记录范围
- 记录结果摘要
- 最近记录列表在治理工具区展示
- 记录按资产维度持久化到 `localStorage`

## 4. 测试设计
新增定向测试：
- 保存并应用导入策略模板
- 导入策略模板刷新后仍可恢复
- 保存多个命名快照并切换恢复
- 分级重置后写入重置记录，并在重新挂载后恢复

## 5. 风险与边界
- 本批不调整后端接口，不引入跨页签新路由
- 本批不触碰 disposal/approval 脏文件
- 继续保持整页连续滚动，不把治理工具区做成独立弹窗
