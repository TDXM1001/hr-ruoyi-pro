# 不动产占用状态矩阵第十四批设计

## 1. 目标
本批继续沿用占用矩阵治理线，不增加后端接口，不增加 SQL，只在占用页签内补齐导入治理结果留痕、趋势钻取筛选快照，以及统计重置分级控制能力。

## 2. 范围
仅调整以下文件：
- `art-design-pro/src/views/asset/real-estate/detail/components/occupancy-panel.vue`
- `art-design-pro/tests/views/asset-real-estate-occupancy-panel.test.ts`

## 3. 设计

### 3.1 导入校验报告导出
在“导入预设”预览区新增“导出校验报告”，导出内容聚焦治理而不是字段本身，包含：
- 汇总：可导入数、冲突数、无效数、全局策略
- 冲突项：名称、冲突类型、最终处理策略、导入后名称
- 无效项：名称、无效原因、非法字段

导出格式采用 JSON，便于后续二次导入或审计留档。

### 3.2 冲突处理结果回看与复用
完成导入后，在占用页签内保留“最近一次导入处理结果”卡片，展示：
- 导入时间
- 全局策略
- 导入成功数、跳过数、改名数、覆盖数、无效数
- 最近一次处理明细摘要

同时新增“复用上次处理策略”入口：
- 若当前预览中存在同名冲突项，可按冲突名称匹配上次逐条策略
- 未匹配项继续走当前全局策略
- 系统预设冲突仍不允许覆盖

### 3.3 趋势钻取筛选快照
第十三批已经支持钻取联动到轨迹区，第十四批补“保存”和“恢复”能力：
- 点击趋势柱后，可将当前钻取态保存为一次筛选快照
- 快照记录：时间窗、钻取日期、排序、状态、关键字、自定义范围
- 页面提供“一键恢复快照”与“清空快照”入口
- 快照按资产维度持久化到 `localStorage`

### 3.4 统计重置分级控制
“重置统计”改为分级操作，而不是单一清空：
- 只重置趋势：只清 `events` 与钻取态，保留来源次数
- 只重置来源：只清 `counts / lastTarget`，保留趋势事件
- 全部重置：全部清空并恢复默认时间窗

仍保留二次确认，确认文案随重置范围变化。

## 4. 测试设计
新增定向测试：
- 导出校验报告包含汇总、冲突项和无效项
- 成功导入后生成最近一次处理结果，并可复用逐条策略
- 趋势钻取快照可以保存、恢复、清空
- 分级重置只影响对应统计范围

## 5. 风险与边界
- 本批不调整后端接口，不引入跨页签新路由
- 本批不触碰 disposal/approval 脏文件
- 仍保持整页连续滚动，不回退到局部滚动容器
