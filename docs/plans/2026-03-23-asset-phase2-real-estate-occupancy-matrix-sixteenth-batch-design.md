# 不动产占用状态矩阵第十六批设计

## 1. 目标
本批继续沿用占用矩阵治理线，不增加后端接口，不增加 SQL，只在占用页签内补齐治理审计能力，把策略模板、趋势快照、重置记录从“可用”提升到“可追溯、可对比、可导出”。

## 2. 范围
仅调整以下文件：
- `art-design-pro/src/views/asset/real-estate/detail/components/occupancy-panel.vue`
- `art-design-pro/tests/views/asset-real-estate-occupancy-panel.test.ts`

## 3. 设计

### 3.1 策略模板审计
在治理工具区的“导入策略模板”中，补齐模板审计信息：
- 创建时间
- 最近一次应用时间
- 最近一次应用结果摘要
- 模板详情查看入口

模板详情展示：
- 全局策略
- 逐条覆盖策略数量
- 最近一次命中的冲突数量
- 最近一次应用生成的结果摘要

目标是让策略模板不再是黑盒，便于资产管理员回看治理动作。

### 3.2 趋势快照差异对比
在“趋势快照管理”中支持选择两个快照进行差异对比，对比维度包括：
- 时间窗
- 钻取日期
- 状态筛选
- 关键字
- 自定义时间范围
- 排序方式

对比结果按三类输出：
- 一致项
- 差异项
- 核心变化摘要

差异对比只在治理工具区内展示，不新增独立页面。

### 3.3 重置记录审计
在“重置记录”中补齐治理审计能力：
- 按范围筛选：趋势 / 来源 / 全部
- 按关键字筛选摘要
- 导出当前筛选后的重置记录 JSON

导出内容包含：
- 记录时间
- 范围
- 摘要
- 当前筛选口径

### 3.4 治理工具区收敛
第十六批不新增新的一级入口，所有新增能力继续收在治理工具区中。
主页面仍以业务浏览为主，治理能力作为辅助区，不侵入总览、轨迹和操作主流程。

## 4. 测试设计
新增定向测试：
- 模板详情与最近应用信息展示
- 两个快照差异对比输出正确
- 重置记录可按范围与关键字筛选
- 重置记录可按当前筛选结果导出 JSON

## 5. 风险与边界
- 本批不改后端接口，不新增 SQL
- 不触碰 disposal/approval 相关脏文件
- 不动 `application-druid.yml`
- 不回退已有治理能力，只做审计增强
