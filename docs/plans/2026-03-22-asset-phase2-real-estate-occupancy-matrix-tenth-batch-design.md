# 不动产占用状态矩阵第十批设计

## 1. 目标

在第九批已经完成“自定义预设复制新建、批注模板化、回跳来源提示”的基础上，继续补齐三个更偏可维护和可追踪的能力：
1. 自定义预设编辑删除
2. 模板预览
3. 来源链路统计

本批仍限定为前端增强，不新增后端接口，不调整数据库结构，不改变占用业务状态机。

## 2. 设计边界

### 2.1 保持不变

- 不新增 SQL
- 不修改占用相关后端接口
- 不新增独立页面
- 不调整占用发起、变更、释放的业务规则
- 不改动巡检、整改、处置的数据结构

### 2.2 本批新增

- 自定义导出预设支持编辑名称、用当前字段覆盖、删除
- 批注模板支持预览展示，用户切换前能先看文案口径
- 占用页签记录跨页签联动统计，并按资产维度持久化

## 3. 交互设计

### 3.1 自定义预设编辑删除

在“导出字段配置”面板中新增“自定义预设管理”：
- 每个自定义预设显示：
  - 名称
  - 编辑按钮
  - 删除按钮
- 编辑动作：
  - 载入当前预设名称
  - 使用当前字段配置作为待保存字段
  - 点击“保存预设”后覆盖原预设
- 删除动作：
  - 立即删除该预设
  - 若当前选中字段来自该预设，不强制重置字段，仅删除预设项

### 3.2 模板预览

在“批注模板”区域下方新增模板预览卡：
- 展示当前模板下的：
  - 状态说明样例
  - 占用批注样例
  - 释放批注样例
- 预览数据优先取当前有效占用，否则取第一条轨迹
- 预览只做阅读，不影响真实数据

### 3.3 来源链路统计

在“跨页签联动”区域下方新增“来源链路统计”：
- 统计维度：
  - 回总览核对主档
  - 看巡检联动
  - 看整改进展
  - 看处置关联
- 统计口径：
  - 本资产累计点击次数
  - 最近一次联动目标
- 持久化到 `localStorage`
- 只做前端统计，不回写后端

## 5. 测试设计

### 5.1 定向测试

新增测试场景：
1. 自定义预设可编辑并覆盖字段集合
2. 自定义预设可删除且刷新后不恢复
3. 批注模板切换后预览区文案同步变化
4. 点击跨页签联动后统计计数增加并在重挂载后恢复

### 5.2 回归测试

继续覆盖不动产详情相关页面，确保不影响：
- 占用页签既有筛选、分组、导出、来源提示
- 巡检任务页
- 整改单页
- 整改完成页
- 整改审批挂载位
