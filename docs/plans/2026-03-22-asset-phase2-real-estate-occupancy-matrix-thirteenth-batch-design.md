# 不动产占用状态矩阵第十三批设计

## 1. 目标
本批继续沿用占用矩阵治理线，不增加后端接口，不增加 SQL，只在占用页签内补齐导入治理、趋势钻取联动和统计重置保护能力。

## 2. 范围
仅调整以下文件：
- `art-design-pro/src/views/asset/real-estate/detail/components/occupancy-panel.vue`
- `art-design-pro/tests/views/asset-real-estate-occupancy-panel.test.ts`

## 3. 设计

### 3.1 导入校验报告
在“导入预设”区域新增校验报告卡片，分为三层：
- 汇总：可导入数、冲突数、无效数
- 明细：每条预设的名称、字段数、非法字段、冲突类型
- 处理：每条冲突项支持单独覆盖全局策略

无效项包括：
- 名称为空
- 有效字段为空
- 字段全部非法

冲突类型包括：
- 系统预设重名
- 自定义预设重名

### 3.2 单条冲突处理
保留第十二批的全局策略：
- 跳过
- 自动改名
- 覆盖

在此基础上，每条冲突记录新增单条处理策略。执行顺序为：
1. 若该条配置了单条策略，则以单条策略为准
2. 否则回退到全局策略

约束：
- 系统预设冲突不允许覆盖，只允许跳过或自动改名
- 自定义预设冲突允许覆盖

### 3.3 趋势钻取联动轨迹区
点击趋势柱后，除了展示钻取摘要，还要联动轨迹区：
- 自动切换历史记录时间筛选到对应自然日
- 记录钻取前筛选快照
- 滚动到轨迹区
- 在轨迹标题区显示“当前来自趋势钻取”

取消钻取后：
- 恢复钻取前时间筛选
- 清空钻取标记

### 3.4 重置统计二次确认
点击“重置统计”时先弹确认。

确认后执行：
- 清空来源链路统计
- 清空趋势事件
- 清空钻取态
- 恢复默认时间窗为近 7 天

取消后保持现状。

## 4. 测试设计
新增定向测试：
- 导入校验报告输出汇总与无效项
- 单条冲突策略覆盖全局策略
- 趋势钻取联动轨迹筛选并可恢复
- 重置统计需要确认后才真正执行

## 5. 风险与边界
- 本批不调整后端接口，不引入跨页签新路由
- 本批不触碰 disposal/approval 脏文件
- 页面滚动仍保持整页连续滚动，不回退到局部滚动容器
