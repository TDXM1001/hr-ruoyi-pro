# 不动产占用管理状态矩阵第十七批设计

## 1. 设计目标

第十七批继续沿用“治理归档型”方向，不再横向扩展新的业务操作，而是把前面第十三批到第十六批形成的治理能力收束成一条可回看、可筛选、可导出的治理闭环。

本批只处理不动产详情页中的占用页签治理区，不改后端接口、不新增 SQL，也不碰处置/审批脏文件。

## 2. 设计范围

- `art-design-pro/src/views/asset/real-estate/detail/components/occupancy-panel.vue`
- `art-design-pro/tests/views/asset-real-estate-occupancy-panel.test.ts`

新增文档：

## 3. 功能设计

### 3.1 治理摘要卡

在治理工具区顶部增加“当前治理状态”摘要卡，帮助资产管理员在展开治理区后先看到整体情况，再决定是否下钻。

摘要卡展示：

- 当前策略模板数
- 当前趋势快照数
- 最近一次治理动作
- 最近一次治理审计包导出时间

最近一次治理动作从治理活动流反推，优先显示最新一条活动摘要；没有活动时显示“暂无”。

### 3.2 治理活动流

新增“最近治理活动”面板，统一展示以下治理动作：

- 应用策略模板
- 保存趋势快照
- 恢复趋势快照
- 删除趋势快照
- 重置统计
- 导出治理审计包

每条活动记录包含：

- 动作类型
- 执行时间
- 影响对象
- 摘要结果

活动流支持：

- 类型筛选：全部 / 模板 / 快照 / 重置 / 导出
- 关键字筛选：匹配对象名称与摘要

### 3.3 治理审计包导出

新增“导出治理审计包”能力，导出当前资产占用治理状态的完整 JSON 包，供留档、交接和复盘使用。

治理审计包内容包括：

- 当前导出字段配置
- 系统预设命名
- 自定义导出预设
- 最近一次导入结果
- 导入策略模板
- 趋势快照列表与当前快照
- 重置记录
- 来源链路统计摘要
- 最近治理活动
- 导出时间

文件名约定：

- `<assetCode>-occupancy-governance-audit.json`

### 3.4 行为留痕

为保证治理摘要卡和治理活动流可用，本批需要把以下动作写入治理活动记录：

- 保存策略模板
- 应用策略模板
- 删除策略模板
- 保存趋势快照
- 恢复趋势快照
- 删除趋势快照
- 执行重置
- 导出治理审计包

活动记录按资产编码维度持久化到 `localStorage`，避免刷新后丢失。

## 4. 数据与持久化设计

新增本地持久化键：

- `asset-real-estate-occupancy-governance-activities:<assetCode>`
- `asset-real-estate-occupancy-governance-export-meta:<assetCode>`

建议新增状态结构：

- `target`
- `summary`
- `executedAt`

## 5. 交互设计

### 5.1 交互原则

- 不新增一级入口
- 治理功能继续收纳在治理工具区
- 占用页签主视图仍以业务阅读为主，治理区保持辅助定位

### 5.2 治理摘要卡

摘要卡位于治理工具区最上方，采用四宫格信息卡样式：

- 模板数
- 快照数
- 最近动作
- 最近导出

### 5.3 治理活动流

活动流展示最近 8 条，默认按时间倒序。

活动筛选区放在活动流头部：

- 类型筛选按钮
- 关键字输入框

### 5.4 导出治理审计包

导出按钮放在治理工具区头部或摘要卡侧边，避免埋在已有模块内部。

## 6. 风险与控制

### 6.1 页面进一步膨胀

控制方式：

- 不新增新页签
- 不新增新弹层
- 所有治理增强都收束在治理区

### 6.2 本地存储结构继续膨胀

控制方式：

- 活动流数量限制在最近 20 条
- 审计导出元数据只保留最近一次

### 6.3 审计包内容与当前 UI 不一致

控制方式：

- 导出时统一从当前响应式状态组装，不从多个中间副本读取

## 7. 验证策略

本批继续采用 TDD：

1. 先补失败测试
2. 验证测试确实失败
3. 写最小实现
4. 跑定向测试
5. 跑占用页签回归测试

重点验证：

- 治理摘要卡展示
- 治理活动流与筛选
- 治理审计包导出内容
- 最近导出时间留痕
